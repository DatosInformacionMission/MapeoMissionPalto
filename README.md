# Aplicación de Login en Flutter 🚀

Este es un proyecto de Flutter básico listo para ser abierto e importado directamente en **Visual Studio Code** o **GitHub Codespaces**.

## ☁️ Cómo ejecutar en GitHub Codespaces

1. Crea un repositorio en GitHub y sube este proyecto.
2. Haz clic en el botón verde **Code** > Pestaña **Codespaces**.
3. Haz clic en **Create codespace on main**.
4. ¡Codespaces instalará Flutter y las extensiones automáticamente!
5. Ejecuta en la terminal de Codespaces:
   ```bash
   flutter run -d web-server --web-port=8080
   ```

## 🛠️ Pasos para ejecutar en VS Code Local

1. Abre Visual Studio Code.
2. Ve a `Archivo > Abrir Carpeta...` y selecciona esta carpeta.
3. Abre la terminal (`Ctrl+` ` o `Cmd+` `) y ejecuta:
   ```bash
   flutter pub get
   ```
4. Conecta tu emulador o dispositivo y presiona `F5`.
