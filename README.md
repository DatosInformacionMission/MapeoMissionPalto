# Aplicación de Login en Flutter 🚀

Este es un proyecto de Flutter básico listo para ser abierto e importado directamente en **Visual Studio Code**.

## 🛠️ Pasos para ejecutar en Visual Studio Code

1. Abre Visual Studio Code.
2. Ve a `Archivo > Abrir Carpeta...` y selecciona esta carpeta.
3. Abre la terminal (`Ctrl+` ` o `Cmd+` `) y ejecuta:
   ```bash
   flutter pub get
   ```
4. Conecta tu emulador o dispositivo y presiona `F5`.
